# Capital Quiz: Survival Mode 

Интерактивная игра-викторина на Python, где нужно угадывать столицы стран. Построена на **CustomTkinter** для крутого современного вида.

##  Особенности
**Survival Mode**: Игра на вылет — ошибаться нельзя (почти).
**Система звезд**: За каждые 10 очков дается "звезда", которая спасает при одной ошибке.
**Рекорды**: Лучший результат сохраняется автоматически.
**Управление**: Мышка или клавиши **1, 2, 3, 4**.

##  Технологии
 Python 3.x
 CustomTkinter (GUI)
JSON (хранение рекордов)

##  Как запустить
1. Установи библиотеку: `pip install customtkinter`
2. Запусти файл: `python main.py`
